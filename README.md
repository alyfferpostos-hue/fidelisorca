# ORÇAPDF - Gerador de Orçamentos Profissionais em PDF

O **ORÇAPDF** é um aplicativo web completo, rápido e 100% gratuito projetado para ajudar trabalhadores informais, autônomos, microempreendedores (MEI) e prestadores de serviço a emitirem propostas e orçamentos profissionais em PDF diretamente do celular ou computador.

---

## 🚀 Como Publicar no GitHub + Render (Passo a Passo)

### 1. Enviar para o GitHub
1. Extraia o conteúdo deste arquivo `.zip`.
2. Acesse sua conta no [GitHub](https://github.com) e crie um repositório chamado `orcapdf`.
3. Faça o upload de todos os arquivos (`index.html`, `robots.txt`, `sitemap.xml`, `README.md`) para a raiz do repositório.

### 2. Publicar Gratuitamente no Render
1. Acesse o [Render](https://render.com) e faça login.
2. Clique no botão **New +** > **Static Site**.
3. Conecte sua conta do GitHub e selecione o repositório `orcapdf`.
4. Deixe o campo **Build Command** em branco.
5. Defina o **Publish Directory** como `./` ou `.`.
6. Clique em **Create Static Site**. Seu site estará no ar em poucos segundos com SSL (HTTPS) gratuito!

---

## 🌐 Configuração de Domínio Próprio (Registro.br)

Para maximizar o SEO e a aceitação no Google AdSense:
1. Registre o domínio `orcapdf.com.br` no [Registro.br](https://registro.br).
2. No painel do Render, vá em **Settings** > **Custom Domains** e adicione `orcapdf.com.br`.
3. Configure os apontamentos DNS (CNAME e A) conforme indicado no painel do Render.

## 💰 Monetização com Google AdSense

O código do `index.html` já possui:
- Estrutura pronta para banners de topo e conteúdo.
- Páginas legais obrigatórias (Política de Privacidade e Termos de Uso em Modais).
- Textos explicativos e FAQ para atender o critério de conteúdo de alto valor.

**Para ativar os anúncios:**
1. Cadastre o domínio no [Google AdSense](https://adsense.google.com).
2. Cole a tag do AdSense `<script async src="..."></script>` dentro da tag `<head>` no `index.html`.
3. Substitua as `<div>` com classe `adsense-slot` pelos seus blocos de anúncio oficiais.
